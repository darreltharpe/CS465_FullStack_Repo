    Why did the backend use a NoSQL MongoDB database?

While a relational database could have handled the data in this particular program, it being consistently structured, MonogoDB is an integral part of the MEAN stack with much support for integration with the other components, including and especially Mongoose, which provides a convenient bridge between MongoDB and Node, making MongoDB an easy choice.

    How is JSON different from Javascript and how does JSON tie together the frontend and backend development pieces?

JSON, or Javascript Object Notation, is a format used for transfering data, while Javascript is a high level programming language. While JSON is based on Javascript syntax, it works with any language. JSON ties the front and back end together because it is the format of choice for data being transfered between the browser and the server.

    Methods for request and retrieval necessitate various types of API testing of endpoints, in addition to the difficulties of testing with added layers of security. Explain your understanding of methods, endpoints, and security in a full stack application.
    
Methods are simply functions that are tied to an object or class. Endpoints are specific URLs where APIs send requests or recieve data. Security in a full stack application is a complex and multifaceted topic, and involves protecting the application both from outside threats and internal malfunctions. Endpoints are of particular interst in security, as they serve as a vulnerable gateway through which malicious code can enter.
